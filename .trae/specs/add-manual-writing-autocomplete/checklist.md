# Checklist

- [x] 点击"开始写下一章"弹出写作模式选择（AI 自动 / 手动辅助）
- [x] 选择"AI 自动写作"行为与改造前一致（流式生成、审查、保存）
- [x] 选择"手动写作"进入可立即输入的编辑器，光标聚焦
- [x] 手动写作停顿约 1 秒后触发续写建议请求
- [x] 续写建议以灰色建议条形式显示在编辑器下方（含 Tab 接受 / Esc 忽略提示）
- [x] 建议内容基于当前正文 + 章节大纲 + 全文大纲 + RAG + 故事知识 + 写作元数据
- [x] 建议为一段续写片段（约 100-300 字），不重复已有内容
- [x] Tab 键接受建议并追加到正文，幽灵文本清除
- [x] Esc 键清除当前建议
- [x] 继续输入时旧建议立即清除并中止在途请求
- [x] 用户再次停顿时依据更新后正文重新请求新建议
- [x] write_chapter 与 write_chapter_stream 共用 _build_writing_context，无重复上下文构建
- [x] POST /suggest 端点返回 {suggestion} 且不改数据库状态
- [x] LLM 失败时 /suggest 返回空建议而非 500
- [x] 手动模式点击"保存章节"走 /save 链路（持久化 + 版本 + 知识抽取 + 语义 + 向量）
- [x] 手动保存后知识图谱可反映新章知识
- [x] 服务器正常启动，模式选择->手动写作->Tab 补全->保存全流程端到端通过
